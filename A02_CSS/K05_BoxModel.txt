
MODELO DE CAJAS DE CSS (BOX MODEL)
==================================

Las CAJAS css, el CONTENIDO esta envuelto en una caja de PADDING, el padding
está dentro de otra caja llamada BORDE, el borde este contenido en la caja del
MARGE


    +-----------------------------------------------------------------------+
    |              MARGIN                       Top                         |
    |   +---------------------------------------------------------------+   |
    |   |               BORDER                  Top                     |   |
    |   |   +-------------------------------------------------------+   |   |
    |   |   |                 PADDING           Top                 |   |   |  
    | L | L | L +-----------------------------------------------+ R | R | R |
    | e | e | e |                  CONTENT                      | i | i | i |
    | f | f | f |                                               | g | g | g |
    | t | t | t +-----------------------------------------------+ h | h | h |
    |   |   |                                   Bottom            t | t | t |
    |   |   +-------------------------------------------------------+   |   |
    |   |                                       Botom                   |   |
    |   +---------------------------------------------------------------+   |
    |                                           Botom                       |
